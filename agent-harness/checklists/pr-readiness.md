# Pull Request Readiness Checklist

- [ ] Scope matches one issue-sized change or clearly linked sub-issues.
- [ ] `feature_list.json` was updated when scope, status, or issue numbers changed.
- [ ] Decision records were added for durable workflow or architecture choices.
- [ ] `node scripts/quality-gate.mjs` passed or skips are explained.
- [ ] Package script and dependency changes are listed in the pull request.
- [ ] No source or asset paths were changed by a harness-only contribution.
- [ ] Pull request title uses a conventional commit prefix.
