# Agent Harness Area Guide

This area owns contributor coordination and delivery protocols.

## Scope

- `agent-map.json`
- `schemas/**`
- `protocols/**`
- `templates/**`
- `checklists/**`

## Rules

- Keep files general enough for parallel contributors to follow.
- Do not include implementation details that belong in `src/`.
- When changing a workflow rule, add or update a decision record in `docs/decisions/`.
- Keep JSON files valid and deterministic for scripts.
