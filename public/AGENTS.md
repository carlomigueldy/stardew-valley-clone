# Public Assets Agent Guide

## File map

- `assets/pixel/` contains local pixel-art-style SVG support assets and provenance notes.
- `assets/pixel/README.md` documents asset provenance and generation rules.
- `assets/pixel/quest-star.svg` is the Rowan quest marker.
- `assets/pixel/market-ribbon.svg` is the market stall banner.

## Rules

- Do not use PixelLab MCP.
- Keep assets original, local/offline, and compatible with the repository license.
- Update `assets/pixel/README.md` when adding asset sources or generation steps.
- Run `npm run generate:assets` if editing generated SVG support assets.
