# Pixel asset provenance

These SVG support assets are handcrafted deterministic project assets generated by `scripts/generate-assets.mjs`. Runtime character, terrain, crop, weather, and UI textures are drawn from code in `src/game/assets/createPixelArtTextures.ts` using Phaser canvas textures.

- PixelLab MCP was not used.
- Assets are original, local/offline, and intentionally avoid direct Stardew Valley lookalikes.
- License follows the repository license.
